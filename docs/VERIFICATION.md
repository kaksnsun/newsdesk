# 源码基线验证记录

本基线已在 Apple Silicon、macOS 26.5.2、Node.js 24.21.0、npm 11.19.0 上验证。使用独立临时目录、测试资料库和浏览器会话，未使用真实稿件、账户或模型密钥。

| 验证项 | 结果 |
| --- | --- |
| 解压安装 | 从源码 ZIP 解压，成功执行 npm ci、npm run setup:search、npm start。内置搜索使用新生成的配置和密钥 |
| 基础服务 | 浏览器首页可访问，资料库写在指定的临时目录，SearXNG 就绪 |
| 应用回归 | 208 项测试通过 |
| Chrome 实测 | 创建项目、编辑稿件、自动保存、保存失败后另存与重试、导出、备份、恢复、切换目录及重新打开通过 |
| 真实检索 | 普通选题检索取得 10 条候选；单独调用内置搜索的学术来源取得 40 条 |
| Research 全流程 | 通过应用的 Research 接口使用真实内置搜索和本地模拟模型，收到 20 条已评分结果。确认了查询和评分的数据流；分数来自测试响应，不能据此评价真实模型质量 |
| 依赖检查 | npm audit 对锁定的生产依赖报告 0 项已知漏洞。pip-audit 对本次实际安装、具有固定版本的 36 个 Python 发行包报告 0 项；此数不含按提交安装的 SearXNG 自身 |

设置页的默认搜索探测在本次网络下返回 0 条，报告上游拒绝访问、HTTP 错误和限流。同环境下，Research 的来源扩展与学术来源查询均能取得实际结果。上游可用性会随时间和网络环境变化。真实远程模型、Intel Mac、Windows 和 Docker 未在本次验收。

## 隐私与安全边界

- 打包采用文件白名单。未打入 Git 历史及其作者配置、实际资料库、备份、用户导出、旧包、截图、运行环境、日志、缓存、依赖目录或开发机生成的搜索服务密钥。
- 对候选源码、配置、测试、前端资源和交付文档进行凭据特征、个人路径、邮箱及账户标识检查。测试中出现的账号密码是 example 域名的固定测试输入。六幅 JPEG 未发现 EXIF 标签。归档不携带宿主文件扩展属性。
- 出包扫描能发现匹配特征的信息，不能证明不存在未知漏洞，也不能替代发布前的代码与依赖复审。
- 本机单用户运行是本版的边界。默认只监听回环地址。应用允许用户主动配置模型服务地址；使用远程模型与在线搜索时，相应的任务输入会发给对应服务。不要将现有单库服务直接开放给多用户。
