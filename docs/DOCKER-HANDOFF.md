# Docker 适配交接

目标是在每位用户自己的设备上运行 Newsdesk。宿主机通过本地浏览器访问，数据在容器升级、删除及重建后仍可读取。交付的是可原生运行的基线，容器构建、镜像发布和跨平台验收由接手同事完成。

## 进程、地址与访问边界

- 应用入口是 `node server.mjs`。当前主服务将监听地址固定为 `127.0.0.1`，仅端口支持 `PORT`（默认 43219）。容器化时需要让进程监听容器网络接口，宿主端口只发布到宿主机的回环地址。仅添加端口映射无法解决容器内的回环绑定。
- 浏览器应通过 `http://127.0.0.1:43219` 访问。`library-api.mjs` 校验本地 Host、Origin 和专用请求头，其余 API 在 `server.mjs` 中处理。应用是单用户单库设计，没有多人账户隔离。调试容器时应保留这些访问限制。
- 内置搜索由 `search-service.mjs` 分配临时回环端口，启动 `scripts/run-search.py`，轮询其配置接口并管理停止与异常重启。首版优先保持单容器内的进程关系。若拆分搜索服务，需要重新设计启动检测、健康状态、退出处理及故障恢复。搜索服务无需对外发布端口。
- 用户配置的模型地址由 Node 服务访问。容器内的 localhost 指向容器。连接宿主机模型时，要验证所用容器运行环境的宿主地址、模型监听地址和访问权限。流式写作、取消操作和超时行为需实测。
- 保留 `server.mjs` 的 SIGTERM/SIGINT 优雅退出，确保 SearXNG 子进程正常退出。部署检测可读取 `GET /api/search-status`；进一步用一次真实检索确认能取得结果。纯 UI 启动不代表搜索或模型已配置成功。

## 数据目录

| 配置 | 当前作用 | 适配建议 |
| --- | --- | --- |
| `NEWSDESK_DATA_DIR` | 新库的默认目录；含主库与同目录备份 | 绑定用户可见的宿主目录，例如映射为容器内的 `/data` |
| `NEWSDESK_CONFIG_DIR` | 保存位置指针 `location.json` | 使用独立持久化目录，例如 `/config`，重建后保持容器内路径一致 |
| `NEWSDESK_SEARCH_DIR` | 搜索运行目录；含 settings、日志和缓存 | 准备容器可写的搜索目录，避免空挂载遮挡已安装的运行时 |
| `NEWSDESK_SEARCH_PYTHON` | 覆盖搜索工作进程的 Python 可执行文件 | 与当前镜像架构和已安装的 Python 包匹配 |
| `NEWSROOM_BROWSER_PATH` | 动态网页提取的浏览器可执行文件 | 指向镜像内可运行的 Chrome 或 Chromium |

优先从宿主文件夹挂载完整的数据目录。只挂载单个 SQLite 文件会遗漏备份和 SQLite 临时文件。卷必须对运行用户可写，同一资料库应由一个应用实例管理。已有位置指针优先于默认目录变量。挂载丢失时要让用户知道，避免误以为进入了一个新的空资料库。

现有的 macOS 文件夹选择器调用 osascript，其他系统回退为手动输入。容器无法浏览未挂载的宿主目录。需要约定如何修改宿主挂载，以及设置页怎样显示真实可用的位置；保存、移动、还原的冲突与权限检查仍需保留。用户密钥属于浏览器，备份库和镜像均无需包含密钥。

## 依赖与平台

- Node 22.13+，从 `package-lock.json` 用 `npm ci` 安装。SQLite、`@napi-rs/canvas` 及浏览器相关的原生文件需在目标平台安装，不要复制开发机的 node_modules 或 Python 虚拟环境。
- 搜索安装脚本固定 SearXNG 提交、Python 主次版本和 Waitress 版本，见 `search-runtime.lock.json`；其他 Python 依赖目前由安装时解析。构建镜像时应记录或锁定实际解析版本并审计它们。不要把开发机生成的 settings.yml、日志或缓存放进镜像，每个安装生成自己的搜索服务密钥。
- 网页渲染要带浏览器和系统依赖，并保留已有网页请求校验。PDF、DOCX、PPTX、文本导入分别验收。旧 DOC 当前依赖 macOS textutil，旧 PPT 依赖 LibreOffice 的 soffice；要为 Linux 容器确定兼容实现或提供清楚的功能提示。
- 建议验证 Linux arm64 镜像在 Apple Silicon Mac 运行、Linux amd64 镜像在 Intel Mac 和 Windows x64 的 Linux 容器环境中运行。这里是目标矩阵，本源码包的本机验证仅覆盖 Apple Silicon macOS。

## 验收清单

1. 在空挂载目录启动，能创建项目、导入文件、写稿和保存；重启及删除重建容器后可读取原稿。
2. 创建备份，修改稿件，执行整库还原，并确认恢复前快照仍可读取；只读挂载或冲突能显示可操作的错误。
3. 内置搜索启动成功，用公开选题取得真实结果；接入测试模型后完成推荐排序、正文检查、导入和生成。验证搜索不可用及取消任务时的状态。
4. 三种目标宿主分别验证浏览器访问、动态网页提取、文件路径、权限、关闭应用和升级。验证局域网其他设备无法访问默认服务。
5. 镜像与构建上下文仅包含应用和依赖；在镜像层、日志、缓存及版本库中检查资料库、API 密钥和个人路径。发布二进制或镜像时重新核对随包软件的许可证与对应源代码交付要求。
